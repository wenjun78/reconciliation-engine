# ai_logs — raw coding-agent session logs

The assessment requires the raw session logs of the AI tools used, committed here.

## What goes in this directory

* `claude-session_011tQdng5wBc2mbUpDme1N8Q.md` — the transcript of the Claude session in which
  this repository was designed, implemented, tested and benchmarked (session id
  `session_011tQdng5wBc2mbUpDme1N8Q`, 2026-10-16, Asia/Kuala_Lumpur).
* Any later sessions used for fixes, one file each, named `claude-<session-id>.<ext>`.

## How to export

* **Claude Code (terminal):** session transcripts are stored under
  `~/.claude/projects/<project-slug>/<session-id>.jsonl`; copy the file(s) here.
* **Claude app / web (this session):** open the session from the sidebar and use the
  export/download action, or request a full data export (Settings → Privacy → Export data)
  and copy the conversation matching the session id above.

If the tool offers no export, say so in `AI_LOG.md` and describe what was used instead.

## Redaction checklist (public repository)

Before committing a log:

1. Search for credentials and tokens: `grep -nEi 'api[_-]?key|secret|token|password|Bearer ' <file>`.
   None were used in this exercise; anything found is unrelated and must be removed.
2. Remove content from unrelated work or private files that happened to appear in the session.
3. Do **not** redact the working process on this exercise — rejected ideas, failing runs and
   corrections are the point of the log (they are summarised in `AI_LOG.md`).
4. The log may contain the synthetic fixture data; that is fine (it is published).
